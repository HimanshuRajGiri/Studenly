# Studenly 🚀

**Studenly** is a beginner-friendly web project built using **HTML, CSS, and JavaScript**.  
The main goal of this project is to help students **learn JavaScript practically** by building a **real-life useful application**.

---

## 📌 Project Objective

- Clear HTML & CSS basics
- Strong understanding of JavaScript
- Learn DOM manipulation
- Learn event handling
- Learn basic localStorage usage
- Build confidence by creating a real project

---

## 🧠 Project Idea

Studenly is a **Smart Student Daily Life Manager** where students can:
- Manage daily tasks (To-Do List)
- Track expenses
- Write short notes
- Track daily habits

(Current version focuses on **To-Do List**)

---

## 🧑‍🤝‍🧑 Team Work (2 Members)

### 👤 Member 1 – UI Developer
- Create HTML structure
- Design layout using CSS
- Improve UI & responsiveness

### 👤 Member 2 – JavaScript Developer
- Write JavaScript logic
- Handle button click events
- Add / delete tasks
- Work with DOM & localStorage
